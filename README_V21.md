ERICA AI V21 — PDF PROGRAM IMPORTER

New: upload a training PDF, extract its text in the browser with PDF.js, recognize common exercises and prescriptions, preview/edit the structured program, then save it as a mesocycle assigned to a client. The original PDF binary is not stored by this version; metadata and parsed program are stored locally, with mesocycle cloud upsert when available.

Best with text-based PDFs exported from Word/Excel/Google Sheets/programming apps. Scanned/image-only PDFs require OCR, which is a planned next layer.
